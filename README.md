# MediBrief AI - Clinical Decision Support System

MediBrief AI is a multi-tier, modular system that ingests raw, unstructured patient medical records and returns structured clinical insights.

## Project Structure
- `/ai-service`: Python FastAPI microservice for NLP pipeline (SpaCy + Ollama).
- `/backend`: Spring Boot REST API for rule engine and orchestration.
- `/frontend`: React client for the user interface.
