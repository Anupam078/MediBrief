# Release Notes

## v0.1.0 - Initial Release

Released: 2026-05-23

This first version of MediBrief establishes the initial end-to-end platform for clinical note analysis.

### Included

- Python AI service for text preprocessing, entity extraction, and summarization.
- Spring Boot backend for orchestration, rule evaluation, and response shaping.
- React frontend for submitting clinical input and viewing structured results.
- Core project documentation, architecture notes, and implementation planning files.

### Highlights

- First integrated MediBrief codebase committed to GitHub.
- Initial structure for API, backend, frontend, and AI service layers.
- Foundation for future clinical workflow improvements and decision support features.

### Known Gaps

- Service wiring and environment configuration may still require local setup before full execution.
- Production hardening, authentication, and deployment automation are not part of this initial release.
